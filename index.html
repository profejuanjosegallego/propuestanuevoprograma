01 · Nuevo marco

Cinco competencias, cinco submódulos, un ciclo

El estándar recorre el ciclo completo del entorno de programación. Cada competencia específica es un submódulo y conserva su nombre oficial en ambas versiones; lo que cambia entre la Versión A y la B es el contenido con el que se desarrolla.

04 · Versión B

Rediseño con contenidos nuevos

Mismos nombres de submódulo, contenido nuevo y concentrado: la lógica y el modelamiento de problemas son la columna vertebral de los cinco submódulos, cada submódulo tiene un eje dominante y todos construyen un mismo proyecto para un cliente real. Python es el lenguaje principal (lógica, backend, automatización y MCP); el estudiante trabaja desde un laboratorio virtual sin instalar nada en su equipo y aprende a usar, configurar y crear AI Skills.

05 · Desarrollo web y SQL

¿Qué pasa con el desarrollo web y con SQL?

Ninguna de las dos versiones los pierde. El estándar no nombra la web ni las bases de datos, pero son el escenario natural para reconocer, configurar, usar y ejecutar un entorno de programación. En la Versión B el desarrollo web se concentra en un submódulo completo (el 4, de punta a punta con React y FastAPI) y SQL crece y se reparte en dos submódulos.

Recomendación

Adoptar la Versión B como meta y usar la Versión A como transición

El núcleo común hace posible la transición sin cambiar la estructura aprobada: la Versión A arranca con el equipo docente actual y, unidad por unidad, se reemplazan contenidos por los de la Versión B. Primero entra lo que no depende de infraestructura: lógica y modelamiento en los cinco submódulos y el reto de lógica semanal. Después llegan el laboratorio virtual, Python y FastAPI, y por último las Skills, el MCP y la automatización, hasta completar la migración en la cohorte siguiente.
